# Documentation

This folder contains the release-facing docs for Dubs Buddy.

- `INSTALL.md`: user install paths and Codex UI steps
- `STATE_MAPPING.md`: Codex row mapping and animation intent
- `DEVELOPMENT.md`: build pipeline, source assets, QA outputs, and contribution notes
- `PUBLISHING.md`: GitHub release checklist and LinkedIn sharing copy
- `Dubs_Buddy_Setup_Guide.docx`: Word guide for sharing with classmates
